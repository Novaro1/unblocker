## Free DNS / Subdomain Providers

Point these to any server IP or CNAME (use with the main Veil server).

| Provider | Domains |
|---|---|
| DuckDNS | `*.duckdns.org` |
| No-IP | `*.ddns.net`, `*.hopto.org`, `*.zapto.org`, `*.sytes.net`, `*.serveftp.com`, `*.servegame.com`, `*.servehttp.com` + ~70 others |
| Dynu | `*.dynu.com`, `*.ddnsfree.com`, `*.loseyourip.com`, `*.ooguy.com` |
| deSEC | `*.dedyn.io` |
| DynV6 | `*.dynv6.net` |
| EU.org | `*.eu.org` (manual approval) |
| is-a.dev | `*.is-a.dev` (GitHub PR approval) |
| is-a-good.dev | `*.is-a-good.dev`, `*.is-an.app` (GitHub PR approval) |
| js.org | `*.js.org` (GitHub PR approval, JS projects) |
| sslip.io | `*.sslip.io` (IP embedded in hostname, e.g. `10-0-0-1.sslip.io`) |
| nip.io | `*.nip.io` (same concept as sslip.io) |
