FreeDNS Helper

Create FreeDNS subdomains for Veil directly from your browser — no server-side logins, no IP blocks, no CAPTCHA issues.

Download Extension
Install in Chrome
1
Download & unzip
Click the button above to download freedns-extension.zip, then unzip it to a folder on your computer.
2
Open Chrome Extensions
Go to chrome://extensions in your address bar and enable Developer mode using the toggle in the top-right corner.
3
Load unpacked
Click Load unpacked and select the unzipped freedns-extension folder. The extension icon will appear in your toolbar.
4
Configure settings
Click the extension icon → Server Settings and enter your Server IP: 16.59.60.231
Staff only. This extension auto-creates FreeDNS accounts and subdomains directly from your browser. Set the Server IP in the popup settings before creating subdomains.
What it does
Account Creation
Auto-fills the FreeDNS signup form with generated credentials and a real temp email inbox.
Email Verification
Polls the temp inbox automatically and shows a one-click activate button when the email arrives.
Subdomain Creation
Auto-fills the FreeDNS subdomain form with a random Veil name and the proxy IP on any Add Subdomain page.
Local Account Storage
Activated accounts are saved in the extension — export credentials as JSON anytime for backup or sharing with staff.
